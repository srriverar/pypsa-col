# Reviewed researcher inputs

The `.example.csv` files contain **headers only**. They are schemas, not official
data or fake placeholder records. Copy a template to the corresponding `.csv`,
populate it with sourced records, review it, and set `reviewed=true` per row.
Do not mark inferred values as measured merely to pass a validator.

## Electrical data

### `line_overrides.csv`

`line_id,r_ohm,x_ohm,b_siemens,s_nom_mva,source,reviewed`

Must cover every retained candidate Line exactly once. `line_id` is
`osm_line_<OSM way ID>` from `resources/physical-candidate/physical_lines.csv`.
Reactance and nominal capacity must be positive; resistance nonnegative.
All parameter units must be verified, including circuit multiplicity. R/X in
per-unit or current in amperes cannot be inserted here unchanged.

### `transformers.csv`

`name,bus0,bus1,s_nom_mva,x_pu,r_pu,source,reviewed`

Bus names are separate voltage-level IDs from `physical_buses.csv`, not just
substation names. Transformer impedance is per-unit on its own `s_nom_mva` base.
Only supplied transformers connect layers. An intentionally empty reviewed file
can have only headers; this does not imply the real network has no transformers.

### `busmap.csv` (18-region mode)

`bus,region,source,reviewed`

Every candidate bus/junction exactly once, with a versioned official or reviewed
membership citation. `expected_regions=18` checks distinct names, not the
truth of a guessed geographic partition. This is a transport aggregation; see
`docs/NETWORK.md`.

## XM fleet and hydro data

### `resource_busmap.csv`

`resource_code,name,bus,carrier,marginal_cost,efficiency,profile,source,reviewed`

- `resource_code`: exact XM resource code, preserving case and leading characters.
- `name`: unique model generator name.
- `bus`: exact bus name of the selected physical or regional topology.
- `carrier`: `hydro`, `gas`, `coal`, `oil`, `wind`, `solar`, `ror`, `biomass`, etc.
- `marginal_cost`: reviewed **USD/MWh of electrical output**; no implicit FX transform.
- `efficiency`: per-unit; use a justified value. Costs here are already output-based.
- `profile`: required for wind/solar/run-of-river, optional for other resources.
  Named columns in the prepared profiles or `generator_profiles.csv`.

Every resource with positive `CapEfecNeta` in the requested study window must be
accounted for; the adapter does not silently discard unmatched plants. Current
`ListadoRecursos` metadata may omit withdrawn historical plants or contain many
later projects; validate against the historical capacity records.

### `reservoir_map.csv`

`reservoir,resource_code,source,reviewed`

Use the exact **daily observation reservoir name**, e.g. the `Name` field, not
necessarily the abbreviated Code in `ListadoEmbalses`. Each mapped hydro resource
belongs to exactly one reservoir; multiple resources at the **same electrical
bus** can share a store. Different electrical buses or cascaded reservoir sharing
are refused by this simplified adapter. Do not map run-of-river plants to a
fictional reservoir just to reuse a storage unit.

### `river_map.csv`

`river,reservoir,share,source,reviewed`

Use the daily `AporEner/Rio` **Name**, not necessarily the current-list short Code.
Positive shares for each selected river must sum to 1. Each modeled reservoir
requires an allocation. Cascade inflows can include upstream turbine releases;
those transfers must not be double counted as independent natural inflows.
The present adapter is for reviewed non-cascade energy-equivalent groupings only.

### `load_weights.csv`

`bus,weight,source,reviewed`

Nonnegative weights must sum to 1 and refer to existing model buses. This allocates
national demand but does not make it measured nodal load. The normalization must
be justified using reviewed OR/UPME/XM evidence and loss/boundary definitions.

### `generator_profiles.csv` (optional)

First column `snapshot` in naive Colombian local time, remaining columns unique
profile names, values in [0,1], covering every requested hour. Used for reviewed
run-of-river or technology availability profiles not generated by the default
wind/PV adapter. Do not use realized `Gene` as potential without an explicit,
justified counterfactual/availability assumption.

## Never commit secrets or restricted engineering exports

This folder's populated CSV/XLSX files are ignored. Before publishing any approved
crosswalk or data product, verify the dataset's reuse terms and redact secrets.
A public API client license is not automatically a license for all its data.
